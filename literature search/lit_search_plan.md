# Literature Search Plan for MOTrPAC

## Goal
Conduct a comprehensive search for papers that have used or developed the MOTrPAC data from 2016 - 2026.

## Implementations
1. Search PubMed and Europe PMC for papers that have used or developed the MOTrPAC data from 2016 - 2026.
2. Use MCP servers for both resources.
3. Create a markdown file for both resources called results.md with a paragraph per paper that contains.
    a. Paper title
    b. Link to the resource
    c. Short description
    d. DOI
4. For each paper, ensure that the link points to the paper to validate it.
